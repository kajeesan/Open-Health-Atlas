Integrations & privacy

data sources and sharing

Source status

Recent data = an observation within 14 days for Hevy or 3 days for each wearable source. Dates describe recorded observations, not the last successful sync. Hermes shows whether its gateway service is running; it does not verify a Telegram connection or an AI client. Bloodwork dates have no freshness threshold.

Privacy

{% if desktop_mode %} The desktop app opens a local session when you launch it. It does not require a passkey. {% else %} Web deployments use passkey (WebAuthn) sign-in and are intended for one user or a tightly controlled private service. {% endif %} The panel reads health records through a read-only database connection. Changes to health records go through a local broker and validated toolkit commands. An operating-system read-only mount is an additional deployment protection; it is not guaranteed here.

If you connect external Hermes or an MCP-compatible AI client, tool results can be included in conversations sent to your chosen model provider. If you use Telegram, messages also pass through its bot API. Data shared and retained depends on the tools, client, provider, and integrations you configure. The source status above is not a complete inventory of outbound data. Review those settings before sharing health information.

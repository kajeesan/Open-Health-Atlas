## Retired synthetic reference code

The local interpretation providers, taxonomy, gateway, prompt compiler,
in-memory lifecycle stores and injected reference API had only synthetic test
and demo consumers. They and their exclusive tests were removed. No wired UI
field or control was removed. The deterministic engine's shared contracts,
ledger, evidence preparation and validated optional synthesis storage remain,
as do genuine external Hermes integration and browser conversations.

## External dependencies

Hevy, Google, Tailscale or another access layer, systemd, OCR/transcription
programs, messaging gateways, and model providers are independently supplied by
the user. They are not bundled Hermes code;
the generic contracts and adapters are retained where implemented.

# Public example sub-muscle map

This bundled map is a fictional starter configuration for demonstrating the
exercise-to-anatomy pipeline. It is not derived from an individual's routine,
account, workout history, or training plan. Installations can replace it with
their own reviewed map.

The weights are broad involvement tiers, not precise percentages:

- `1.0` — prime mover
- `0.66` — strong synergist
- `0.4` — moderate synergist
- `0.2` — stabilizer or minor assist
- `iso` — primarily isometric contribution in this movement

Every row uses `[B]` to mark a biomechanics-based approximation. These entries
are intended for software demonstration and should not be treated as clinical,
diagnostic, or individualized exercise guidance.
